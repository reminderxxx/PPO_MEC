# 持续请求训练稳定性诊断入口

`scripts/diagnose_stream_stability.py` 是独立、显式启用的真实随机训练诊断，不更改默认算法、reward、动作合同或既有训练入口。先用 `check --contract <frozen.json>` 预检，再用 `run --contract <frozen.json>` 执行一次。

合同必须事前绑定清洁源码、已有协议及输入哈希、固定 seed/日程前缀、原退火预算和资源上限。诊断截断长度与算法 `training_budget` 分开，避免短诊断暗改学习率和熵退火。开启/关闭被动观察器的两侧从相同初始参数和 Python/NumPy/PyTorch RNG 出发，比较真实输出及最终学习状态。

输出只能写入新的、被忽略的 `artifacts/` 私有目录；独占 claim 防止恢复、覆盖、失败自动重试或悄悄扩大上限。日志结构完整不等于科学来源已独立审计，也不意味着策略改善或收敛。覆盖不到的自由动作和空闲路径仍标为未核验。

本入口不评估封存 holdout，不选择 checkpoint，不将原始混合负载回报的平滑曲线当作收敛证明。诊断及后续修改应分别审查；实际命令、冻结合同、运行状态、正负结果和来源收据保留在本地私有产物中。正式论文曲线应固定评估条件和统计口径，并据实际尾部表现判断稳定性。
