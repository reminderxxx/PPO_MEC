# Fast auxiliary gradient probe: frozen plan

- Frozen before any new environment step; authoring commit precedes probe artifacts.
- Scope: diagnosis only. No `learn`, `optimizer.step`, checkpoint writes, training, holdout, search, or policy change.
- Inputs: historical control `cscwd_causal_prepared_state_visibility_matched_20261010_v1` and candidate `cscwd_event_aux_abstention_ab_20261010_v1`, each `sa_ghmappo` seed 7, 17, 29, 43, 61, `selected` and `update96`. At most 20 checkpoint slots; report equal checkpoint hashes rather than treating duplicates as independent. Historical minibatches are unavailable, so historical gradient conflict is **UNVERIFIED**.
- For each frozen checkpoint, seed Python/NumPy/Torch with its original seed, build the original training instance order and `random.Random(seed)`, then collect exactly one fresh, stochastic, on-policy 60-transition batch using `_collect_exact_update_batch` with original `gamma=0.99`, `gae_lambda=0.95`, episode cap 24. Each checkpoint owns its batch; never mix batches. At most 1200 new environment steps. These are **fixed-policy new probes**, not historical training reproduction.
- Load each checkpoint with matching arm config. Reproduce the original executed environment-action PPO loss with its stored old executed-action log probability, original advantage normalization, mechanism transition weights and enabled credit terms where feasible. If any enabled original term cannot be reproduced without model mutation, stop that arm and label it incomplete. Never replace executed-action probability with an inverse canonical head tuple.
- Separately differentiate the same forward graph for executed-action PPO actor, slow CE, fast CE, event CE, and value MSE. Auxiliary components use original `auxiliary_coef`, head weight, confidence and eligible-state denominator; candidate event abstention masks event CE without denominator renormalization. Record raw and weighted gradients, dot, cosine and norms on shared encoder, slow/fast/event actor modules and value module. Zero-norm cosine is `UNDEFINED_ZERO_NORM`.
- Predefined public-state strata: current bundle `ready/missing/unknown` recomputed from primary vehicle current RSU plus `bundle_ready`; estimated missing bundle resident bytes `zero/(0,100 MB]/>100 MB/unknown` using public catalog and current cache; deadline remaining `<=10/(10,40]/>40/unknown` seconds from public deadline and elapsed clock only if both exposed; predicted contact budget `<=5/(5,15]/>15/unknown` seconds from public prediction/context. Report all denominators, including unknown. No realized future as actor input.
- Also report fast target distribution; fast CE eligible count and gradient; local effect of infinitesimal fast-logit/fast-parameter perturbation on executable action-2 probability; selected historical action-2 causal examples remain context only. Paired seed/endpoint summaries retain mixed outcomes and duplicate checkpoint caveat. A local gradient conflict does not prove that removing fast supervision improves performance.
- Failure gates: source hash drift, missing checkpoint, original likelihood mismatch on rollout, non-finite gradient, parameter change, or >1200 steps. Do not adapt sample or bins based on results.
