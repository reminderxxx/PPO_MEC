## 分两道门获取，不先下整包再挑图

**M：仅文件元数据资格。**未来执行前先独立实现只读元数据/收据消费者，使用上述两个固定官方来源；
Mendeley API文档在本轮文本浏览中仅显示加载页面，匿名文件列表能力仍未知。
最多12个HTTP请求、5MiB响应体、10分钟；只读取许可、版本、文件名、ID、大小、文件hash及公开标注记录，图像字节0。
标注仅接受有限UTF-8 JSON/XML/TXT，不取图像压缩包，不执行解析脚本；从外部标注确定类别及ROI后才能选样。
先固定标注文件的版本/ID/大小/URL，再在M限额内取标注、离线确定性选样，最后create-only冻结所选图像URL清单；
发布方没有给文件hash时明确记为缺失，不能把取得后的本地hash伪装成发布前独立hash。
固定版本、文件清单与完整下载URL后再冻结获取manifest及其SHA。GitHub需固定commit，不能以可变master作最终身份。
不能从未知JSON自行猜endpoint、绕过账号/验证码或把镜像作为同一来源；任何认证/限流/HTTP/版本错误保存停止。

若来源仅提供超过下述限额的整包，或没有可追溯单文件/小标注包入口，该来源停在`SMALL_SAMPLE_ACCESS_UNVERIFIED`，
不下载整套数据、不使用HTTP Range远程拼包、不更换来源规避本门。入口资格失败不代表数据集本身无效。

**D：满足M后，单次固定小样本获取。**Helmet可独立先完成6图；ALPR必须同时有3带牌+3明确无牌标签才进入D。
两任务分别保留终端状态，不能把只完成Helmet称为完整12图Q。
整个M+D上限32个HTTP请求、64MiB累计下载body、256MiB新增存储、30分钟（含独立消费者）。
M花费计入总额；图像最多12个、单图最多8MiB/20MP/任边8192像素，逐图解码不批量展开。
附带标签与许可文件也计费。重定向逐跳计请求，目标域/URL须在M冻结；
不自动retry、Range、断点续传、改endpoint或追加样本。失败原件和不确定读取上界全部计入，预算不按成功文件重置。
不取模型、视频或训练权重，不安装依赖，不执行仓库代码，不上传图像或标签。

## 样本与答案在模型输出前冻结

1. Helmet仅选明确Helmet/NoHelmet标注的目标框；YOLO类0/1/2不能与COCO的1/2/3混用。
   每图至多一个指定ROI，框须有效、互不冲突且两边至少32像素；不得把BikeWithRider框当戴盔标签。
   对符合规则的标注项按`SHA256(dataset_version + file_id + object_id + class)`排序，各类取前3项。
2. ALPR带牌例使用作者原始字符串与框，保留中文省份字符；规范化NFKC、拉丁大写及明示分隔符，
   不丢中文、不做O/0猜改。无牌必须有发布方明确的完整图像“无牌”语义；缺框、空字符串或未标注绝不推出`NONE`。
   当前官方页面没有闭合这一无牌门，因此ALPR仍为条件项，不暗减成3图或沿用旧12图。
3. 只按预先规则选样，保留全部所选原图和外部GT、ROI、来源、许可/版本/字节/hash；标签由确定性转换读取，
   不调用模型生成GT。取得后发现标注矛盾、不可读、重复或任务不适用时保存并停止该任务，不挑替补、改prompt求通过。
4. SHA相等、相同牌照或近重复仅能提示重复；缺车辆/人员/视频/采集session身份时仍记`UNVERIFIED`，
   不能仅凭不同文件名、2026发布日期或不同DOI认证物理独立与adapter训练无重叠。
5. 输出前形成`sample_manifest`和独立标签清单，图像输入与GT分离；后续推理输入不能携带文件名中的牌照答案、类别目录或标注。
   Helmet如采用裁剪，需按冻结ROI确定、保存派生关系与SHA，两臂完全相同；这是指定对象分类，不评价检测性能。
   ALPR采用完整原图，两臂同一预处理，不以GT牌照框替模型定位。所有输入改为不含答案的opaque名，
   不把原路径、类别或标注传给模型，也不把裁剪后的Helmet输入称原始完整图。
