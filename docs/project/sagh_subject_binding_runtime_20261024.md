# Opt-in runtime subject boundary contract (2026-10-24)

Experimental branch based on f17707ff0adb24ebc271995c3b3392f6261e1a6a. The default `legacy_unbound_v1` behavior stays unchanged. `VecWorkflowCoreEnv(subject_binding_contract="strict_episode_subject_v1")` is explicit opt-in and rejects formal request protocol composition. This work does not authorize training, real-data rollout, reward/teacher/agent changes or new window selection.

The reset episode subject stays fixed. The environment creates a `subject_binding_snapshot` at the existing per-vehicle prediction lookup boundary, recording origin, decision/prediction vehicle and snapshot time. This witness binds identity and time; it does not validate predictor accuracy, calibration, underlying physics or adapter state transfer. Missing/foreign/stale/future witnesses fail before mobility advancement. Strict control metadata must also carry the same primary_vehicle_id; the existing ActionAdapter already produces this field. Direct callers with missing or foreign control identity fail before mobility. If the subject disappears after mobility advancement, the core raises `SubjectBindingBoundaryError` before reassociation, cache admission, offload resolution, workflow service, prepare consumption or reward computation. The failure is latched: further step attempts raise before another provider step. An explicit reset starts a distinct exposure.

A failed attempted transition can advance mobility once and increment the attempted core step, but applies no old control and has no reward. Do not label it a returned zero-reward transition. No Gym success tuple is returned. `GymVecEnv` requires a per-exposure failure receipt path and a frozen exposure ID when strict mode is enabled. It writes `subject_binding_failure_v1` with EXPOSURE_FAILED, reward=null, reward_available=false, control_applied=false and exposure_in_denominator=true, then reraises the typed boundary. Identical repeat failure writes are idempotent; conflicting receipts never overwrite. Wrapper reset refuses a failed receipt path, preventing implicit retry of the same exposure.

The consumer `summarize_subject_exposures(..., expected_exposure_ids=...)` must match all frozen exposure IDs exactly once; missing, duplicate or unexpected IDs reject aggregation. Any failure yields INCOMPLETE_WITH_FAILURES and mean_reward=null. It never publishes an average excluding failures or assigning invented reward to an unexecuted transition. Existing training consumers have not been adapted to score this new exposure protocol; the mode is not enabled by factories, configs or training entry points.

The previous diagnostic API remains available via `scripts/sagh_subject_binding.py`; shared implementation now resides in `src/runtime/subject_binding.py`. Unit tests call actual core/Gym step on synthetic frame providers and forbid ReplayProvider.step. Frozen legacy default output matches and same-subject strict outputs match after removing only the new snapshot witness. Same-step/history/gap diagnostic tests remain. Full saved-trace guard-prefix replay stops before association/control, retains all rows and original reward components, and marks reconstructed legacy identity separately from native synthetic witness tests.
